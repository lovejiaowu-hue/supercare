# SVG 图标使用规范与 Agent 作业约束

> **文件名**：`AGENT_SVG_ICON_GUIDE.md`  
> **版本**：v1.0 · 2026-10-12  
> **适用对象**：ChatGPT Projects、Codex、WorkBuddy 及其他参与产品设计、HTML Demo、前端开发与代码维护的 AI Agent。  
> **约束等级**：默认强制执行（MUST）。除本指南明确允许的例外外，不得自行变更图标来源。

## 0. 一句话总则（最高优先级）

**所有常规产品 UI 图标，必须来自 Lucide Icons、Tabler Icons、Phosphor Icons 三套成熟 SVG 图标库。除经明确确认的特殊原创手绘需求外，严禁 Agent 自行绘制、生成、拼凑、替换成其他来源的功能图标。**

本规则覆盖页面、导航、按钮、表单、菜单、卡片、状态提示、工具栏、弹窗、运营工作台、后台系统、移动端界面及 HTML 原型。

## 1. 唯一允许的三套常规图标来源

| 优先级         | 图标库                | 官网                           | 推荐使用场景                             | 官方常用包                                                                    |
| ----------- | ------------------ | ---------------------------- | ---------------------------------- | ------------------------------------------------------------------------ |
| **P1 / 默认** | **Lucide Icons**   | <https://lucide.dev/>        | 全站基础 UI、导航、操作、状态、业务流程              | `lucide`, `lucide-react`, `lucide-vue-next`, `lucide-static` 等按技术栈选用     |
| **P2 / 补充** | **Tabler Icons**   | <https://tabler.io/icons>    | Lucide 缺少的业务语义、管理后台、运营与数据场景        | `@tabler/icons`, `@tabler/icons-react`, `@tabler/icons-vue` 等            |
| **P3 / 补充** | **Phosphor Icons** | <https://phosphoricons.com/> | Lucide/Tabler 均不适合时，补充特定语义和不同权重的图标 | `@phosphor-icons/core`, `@phosphor-icons/react`, `@phosphor-icons/vue` 等 |

**检索顺序固定**：Lucide → Tabler → Phosphor。某一套没有合适图标，才能换下一套；不应为图省事直接改用其他库。

- 图标库官网与官方仓库、官方 npm 包是可信来源；优先使用本地 **SVG Icon Hub** 资产库（如项目环境已配置）。
- 可下载官方 SVG 文件到本地并反复复用；须保留对应官方许可证与版权声明。
- 本规范只限定**常规 UI 图标的来源**，不意味着允许忽略具体项目所使用图标库的许可证条款。

## 2. 禁止事项（MUST NOT）

Agent 不得在未取得明确授权的情况下：

1. 自行用 `![svg](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMTAwIiBoZWlnaHQ9IjEwMCI+PHBhdGggLi4uLz48L3N2Zz4=)` 手写新的功能图标、凭想象编造 path，或让 AI 生成替代图标。
2. 使用第三方普通 UI 图标库，例如 Font Awesome、Material Icons、Heroicons、Remix Icon、Bootstrap Icons、Iconify 聚合源等，替代上述三套来源。
3. 用 Emoji、Unicode 特殊字符、图标字体、CSS 伪元素、纯 CSS 绘画代替常规功能图标。
4. 为了满足某个尺寸或颜色，将原始 SVG 的结构随意改画、叠加图形或做出无法追溯来源的变体。
5. 在同一页面无理由混用不同图标风格（如线框与实体混搭、笔画粗细明显不一致）。
6. 将完整图标库无差别打入业务页面，或为了调用一个图标加载数千个图标到浏览器。
7. 通过不稳定的第三方图片 URL、外部 CDN 或非官方镜像提供生产环境必需的图标（除非项目已有明确批准的基础设施规范）。
8. 在未查证实际图标名称时，虚构组件名、SVG 文件名或 npm 导出名。

**已有违规图标**：涉及相应页面修改时，优先替换为三套来源的等价图标；不必未经授权开展与当前任务无关的大规模重构。

## 3. 允许的例外：特殊原创手绘

以下内容**不属于普通 UI 图标**，可以按专项设计需求处理：

- 公司/产品品牌 Logo、独立品牌标识、吉祥物或 IP 角色。
- 明确要求原创绘制的插画、场景图、地图插画、工业结构说明图等非通用图标作品。
- 官方机构、应用、支付渠道等真实品牌的**法定/官方商标图形**（必须使用获授权的官方品牌素材，不用常规图标库冒充）。
- 特定行业极专业的符号，经三库检索确实无法表达，且用户**明确同意手绘**的情况。

**例外流程（强制）**：

1. 先检索三套图标库及近义词。
2. 确认没有满足需求的现成 SVG。
3. 向用户说明缺失语义、建议方案及是否需要原创。
4. **经用户明确批准**后方可绘制，并在交付记录中标注 `custom-approved`、用途与批准依据。

> 用户要求“完全照图还原”但参考图含其他图标时，Agent 仍应先提出以三套标准图标做等价替换；若用户明确指定必须复用其授权的特殊素材，则按用户的具体批准执行。

## 4. 视觉一致性规范

- **默认风格**：线性（outline）、简洁、克制。相同页面、同类控件的图标尽量保持同一来源。
- **优先统一**：尺寸、视觉重心、描边粗细、端点/转角风格及色彩。常规尺寸按项目设计系统采用 16 / 20 / 24 px；不为了视觉一致性自行重画路径。
- **颜色**：跟随组件语义色，优先使用 `currentColor` 或组件 API 的颜色参数；禁用随意写死大量颜色。
- **交互**：图标不可单凭形状承担所有含义；语义不明确时配文字或 tooltip。纯装饰性图标设置 `aria-hidden="true"`；图标按钮提供可访问名称（例如 `aria-label`）。
- **Filled 与 Outline**：同一层级尽量采用一致风格；Phosphor 的 weight 与 Tabler 的 filled 仅用于明确的视觉状态区分，并维持全局一致性。
- **适配**：保证浅色/深色模式及移动端显示清晰，避免拉伸变形；优先保持图标自身 `viewBox` 比例。

## 5. 技术接入与离线复用

优先级：**项目已经安装的官方组件包 → 本地 SVG Icon Hub 官方 SVG → 通过 npm 安装官方包**。

- **React**：优先使用按需导入的 Lucide/Tabler/Phosphor 官方 React 组件。
- **Vue**：优先使用各库官方 Vue 组件（如果存在适用的包）。
- **原生 HTML / 静态 Demo**：使用项目本地的官方 `.svg` 文件，例如 `<img src="./icons/lucide/search.svg" alt="">`；如需用 CSS 控色，采用受控的官方组件/inline SVG 方式，不得修改路径造新图形。
- **其他技术栈**：优先使用官方 SVG 文件，保持可追溯。
- **本地图标中心**：若已经存在 `SVG Icon Hub`，Agent 必须先搜索中心的目录/索引，再考虑安装包或下载；业务项目只复制或引入用到的图标，不将整个素材库复制进产品。
- **版本记录**：资产统一记录来源、官方图标名、样式、版本与许可证；升级时核对更名、删除和视觉变化。

示例（React，按需导入）：

```tsx
import { Search, Settings } from 'lucide-react';

export function Toolbar() {
  return (
    <div>
      <button type="button" aria-label="搜索"><Search size={20} aria-hidden="true" /></button>
      <button type="button" aria-label="设置"><Settings size={20} aria-hidden="true" /></button>
    </div>
  );
}
```

示例（静态 HTML，使用本地官方文件）：

```html
<button type="button" aria-label="搜索">
  <img src="./assets/lucide/search.svg" width="20" height="20" alt="" />
</button>
```

> 注意：示例路径须以实际工程目录为准；禁止因示例存在就虚构资产已经下载。

## 6. Agent 标准执行流程

收到任何 UI、HTML Demo 或前端功能任务时：

1. **识别**本次需要的图标及对应业务语义。
2. **查询**当前项目已安装组件/本地图标资产和官方目录，按 Lucide → Tabler → Phosphor 检索。
3. **选用**现成真实图标，优先复用同一页面已有的图标风格。
4. **实现**按需导入，保持尺寸、颜色和可访问性统一，不改画原始路径。
5. **验证**图标真实存在、正确显示、无 404、无控制台错误、无明显风格冲突。
6. **交付说明**如涉及新增图标，简要注明图标名称与来源；出现例外时注明批准记录。

如果三套库都没有合适图标：**先使用明确文本标签或保留待选状态，并告知用户；绝不默认手绘来补缺。**

## 7. 交付验收清单

- [ ] 页面中的**所有普通 UI 图标**均来自 Lucide / Tabler / Phosphor。
- [ ] 不存在未经批准的手写 SVG 图标、AI 生成图标或第四方通用图标库。
- [ ] 同一页面的图标尺寸、风格、粗细、颜色一致。
- [ ] 源码中的图标组件名 / 文件名真实存在，页面加载正常。
- [ ] 交互图标按钮具有可访问名称；装饰性图标不造成重复读屏。
- [ ] SVG 资产能离线显示（当项目要求离线时）。
- [ ] 依赖按需引入，无整库误打包。
- [ ] 新增资源的来源、版本和许可证可追溯。
- [ ] 特殊原创图标均已明确批准并留下说明。

**验收红线**：只要存在未经授权的非三库普通 UI 图标，即判定图标规范不通过；Agent 应优先修复该项，再声明任务完成。
