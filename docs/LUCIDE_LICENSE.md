# Lucide 图标来源、许可与版本追溯

本项目 `src/icons.js` 中的图标图形来自 Lucide Icons 官方仓库：
https://github.com/lucide-icons/lucide/tree/main/icons

获取与核验日期：2026-10-26（main 分支）。图标名见 `iconNames`，只保留项目使用的部分 SVG 节点，没有重新绘制 path 数据。对组件尺寸、描边色的设置仅采用 SVG 公共属性。

许可：Lucide 项目采用 ISC；部分继承 Feather 的图标另采用 MIT。详见官方完整许可证及版权要求：
